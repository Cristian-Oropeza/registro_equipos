# Registro de Equipos

Aplicación web full stack para el registro y consulta de equipos de fútbol.

## Estructura

```
backend/    API REST
frontend/   Cliente web
```

## Stack

- **Lenguaje principal:** TypeScript
- **Arquitectura:** Separación cliente/servidor

## Cómo correrlo

Instalar dependencias y correr cada capa por separado:

```bash
cd backend && npm install && npm start
cd frontend && npm install && npm start
```
